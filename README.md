# Computer-Networking

This repository contains my school work for the Computer Networking course, including 4 labs, 1 assignment, and 2 written assignments.


## Labs

#### Lab 1: Socket Programming
Implemented a simple client-server application using socket programming in Python.
Demonstrated understanding of socket programming concepts, including connection establishment, data transfer, and connection termination.

#### Lab 2# : TCP Trace Analysis
Analyzed a TCP trace file to understand the TCP protocol and its behavior.
Identified and explained various TCP protocol mechanisms, including connection establishment, data transfer, and connection termination.

#### Lab 3: IP Trace Analysis
Analyzed an IP trace file to understand the IP protocol and its behavior.
Identified and explained various IP protocol mechanisms, including routing, fragmentation, and reassembly.

#### Lab 4: Ethernet and ARP
Implemented a simple Ethernet and ARP protocol using Python.
Demonstrated understanding of Ethernet and ARP protocol concepts, including frame structure, addressing, and protocol operation.


## Programming Assignment


#### A Simple Game House Application
Designed and implemented a simple game house application using computer networking concepts.
Demonstrated understanding of computer networking concepts, including socket programming, TCP/IP protocol, and network architecture.


## Written Assignment


#### Written Assignment 1
Answered questions related to network protocols and error control mechanisms, including network performance, peer-to-peer (P2P) distribution, transport-layer protocols, and error control mechanisms. The questions require us to analyze network scenarios, calculate distribution times, identify port values and IP addresses, and explain the behavior of protocols such as Go-back-N (GBN), Selective Repeat (SR), and TCP. 

#### Written Assignment 2
Answered questions related to network protocols and routing fundamentals, including forwarding tables, subnetting, shortest-path algorithms, distance-vector algorithms, Internet checksums, and LAN interconnection. The questions require us to design a forwarding table, determine link interfaces for given destination addresses, assign IP addresses and MAC addresses to network devices, compute shortest paths and distance tables, and apply algorithms such as Dijkstra's shortest-path algorithm and the distance-vector algorithm to solve network problems.
